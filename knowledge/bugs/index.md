# Bugs
* [infra init and schema defaults still point at frozen llmaven-* images](image-defaults-point-at-frozen-packages.md) - CI publishes ghcr.io/uw-ssec/llmoxie-*, but defaults name ghcr.io/uw-ssec/llmaven-*:latest, so a freshly generated config gets images that no longer receive releases.
* [The configured subscription has two paths, and az account show doesn't prove the login works](azure-subscription-and-expired-login.md) - Azure CLI calls and the Pulumi provider must each receive the configured subscription, and only a token probe detects an expired login; the backup stack's provider still follows the CLI default.
* [Key Vault access policies get wiped by two separate mechanisms](key-vault-access-policy-replace.md) - keyvault.AccessPolicy replaces rather than adds, and updating the Vault rewrites its list, so the stack uses one shared identity and ignores policy changes on the vault.
* [Backup job defaults disagree with the docs and may miss the important database](backup-job-default-traps.md) - backup_job.database defaults to llmaven, not litellm_db or mlflow_db, and connection_string_env, schedule and restore path differ from the README runbook.
* [A failed pg_dump can leave a truncated blob that counts toward retention](failed-pg-dump-can-consume-retention.md) - backup_postgres.py checks the exit code after the upload closes, and pruning keeps the newest keep_last_n by name, so truncated dumps can push out good ones (inferred, not reproduced).
* [llmaven-backup-config.yaml isn't covered by .gitignore](backup-config-not-gitignored.md) - The Pixi backup task reads llmaven-backup-config.yaml, which the llmaven-config*.yaml glob doesn't match, so the gitignored-configs rule doesn't protect it.
* [infra extract has no pagination, and a malformed response still skips a day](infra-extract-completeness.md) - PR #167's title is misleading: the merged code adds a database export, not pagination, and a non-list body still warns and skips while the run succeeds.
* [CLI tidy-ups can corrupt captured values](cli-output-data-safety.md) - Routing all output through Rich wrapped a long PostgreSQL URI captured by a shell, so the backup-infra output value stays on typer.echo.
* [CI was once green while tests failed, and two traps make CI failures hard to reproduce](ci-false-green-and-repro-traps.md) - The core test step ended in || echo until #184; the pre-commit Pixi task shadows the binary, and Rich colors Typer errors only under GITHUB_ACTIONS.
