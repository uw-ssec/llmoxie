# Decisions
* [The repo is the LiteLLM and MLflow platform only; RAG lives in llmoxie-rag](platform-only-scope.md) - The Sunset RAG milestone removed the REST API, UI, agentic RAG and Qdrant, and tests/test_platform_scope.py fails if they return.
* [New data-pipeline features belong in llmoxie-analysis, not src/llmaven/data](data-pipeline-moves-to-llmoxie-analysis.md) - The source-adapter PRs were closed because the data pipeline is moving to uw-ssec/llmoxie-analysis; src/llmaven/data still ships on main.
* [The llmoxie rebrand must not rename identifiers that carry live state](rebrand-keeps-deployed-identifiers.md) - Pulumi project, project.name, Postgres names, blob containers and the compose volume identify live resources; renaming them orphans state or replaces data.
* [Making a deploy a true no-op: revisions, probes and the preview gate](no-op-deploy-controls.md) - deploy --expect-no-changes previews first because Pulumi's own flag errors only after applying; REFRESH_TRIGGER defaults to the current time, and only LiteLLM can pin it.
* [LiteLLM is pinned by version and digest, and upgrades across migrations are one-way](litellm-image-digest-pin-and-one-way-upgrade.md) - The image is v1.106.6 by digest because of upstream compromises; Prisma migrations are one-way, so rollback means restoring a pg_dump, not swapping the image.
* [LiteLLM stays as the gateway; OSS limits shape what must be built around it](stay-on-oss-litellm-gateway.md) - Moving to MLflow's AI Gateway was recommended against as of 2026-10-30, and OSS LiteLLM refuses Admin UI SSO past 5 user rows, which limits what can be built on it.
* [infra extract sits under infra and writes day-partitioned JSONL](infra-extract-design.md) - The project owner placed it under infra because it reads the main infrastructure, and specified one JSONL file per day; MLflow exports partition by experiment and JSONL has an exact newline contract.
* [Config updates use a ruamel.yaml round-trip, not regex or PyYAML](config-updates-ruamel-round-trip.md) - The generated config has comments PyYAML would drop; regex was accepted only as a stopgap, and #138 replaced it with ruamel.yaml.
* [Azurite replaced MinIO for local MLflow artifacts](minio-replaced-by-azurite.md) - MinIO only backed local artifacts and upstream is archived, so local storage now matches production through wasbs://; old .env files and stored experiment locations are the upgrade trap.
* [Releases use CalVer vYYYY.M.MICRO, with the version from hatch-vcs (planned)](calver-with-hatch-vcs.md) - Project owner's decision in #213: three unpadded parts because metadata-action skips invalid semver; __version__ is still hard-coded and there's no CHANGELOG yet.
* [Monitoring alerts are email-only, opt-in per environment, and the budget is scoped to the resource group](monitoring-alerts-config.md) - Alerting uses one email action group, absolute thresholds listed in enabled_alerts, a resource-group-scoped budget with no tag filter, and Maximum-per-podName for restarts.
